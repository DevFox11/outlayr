# Project Environment

Inspected 2026-08-13 via argent-environment-inspector; refreshed 2026-10-25.

- **Type:** Expo SDK 58.0.17 / RN 0.88.0 / React 19.3.0 in `apps/native` (expo-router, expo-dev-client). Convex in `packages/backend`. Vite+ (`vp`) manages pnpm and is the task runner, linter and formatter.
- **React Native:** yes. Primary target iOS; an Android script exists. Not Expo Go.
- **Bundle id:** `com.tryoutlayr.app`. App group `group.com.tryoutlayr.app`. Scheme `outlayr://`.
- **Metro:** default `8081`. Preferred start: `vp run --filter @outlayr/native dev` (`intlayer build && expo start --dev-client --clear`). Simulator preview `http://localhost:8081/.sim`.
- **Run iOS:** `vp run --filter @outlayr/native ios` (`expo run:ios`). `ios/` and `android/` are gitignored and generated by prebuild.
- **Icons:** Lucide (ISC) from the public registry, `lucide-react-native/icons/<name>` one file at a time; `lucide-static` feeds the generated native symbol SVGs (`gen:icons`). No private registry, no token.
- **Do not** run `serve-sim --kill` while Metro is up.
- **Tests:** `vp run --filter @outlayr/native test` (Jest). Lint via `vp check` / `vp check --fix` (never raw `oxlint`/`ultracite` — the config is the `lint`/`fmt` blocks in `vite.config.ts`).
- **Windows:** `.gitattributes` pins LF, so `vp check --fix` no longer rewrites the tree. Run `pnpm install --ignore-scripts` (the root `prepare` is POSIX) and `pnpm rebuild better-sqlite3` before Jest.
- **Cloud optional:** local-first without `EXPO_PUBLIC_CONVEX_URL`. Agent sim for this personality work: `B6ACCF77-ECC8-45DB-AD38-EF24DE351C58` (Outlayr Agent Sim). Do not touch personal sim `18F283B4-4BF8-4FA5-A362-ED6488A20987`.
